Today is a lecture "Open your Eyes: An Introduction to Seeing"

Computer inputs are simply digitising descriptions of the world into 2D space. Be it coordinates (points), lines, shapes etc. Typically, computers deal with numbers (think: breaking ligatures into numbers)

Word -> camera -> pixels -> patterns -> meaning.

I learned that image processing works by dividing an images into patches, which become visual tokens and allow for the model to match/align with it's training data. It works very closely to how text is processed, whereas I originally thought it was a completely different system.

Latent space = where the descriptions of each token is, a searchable repository that can reveal how the AI is understanding the input.

AlexNet was the beginning of visual systems. It took an image, filtered into edges, colours, textures, and connected all the layers together into an understanding of how these characteristics equal the object shown.
