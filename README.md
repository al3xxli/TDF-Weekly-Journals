This is a collection of my Obsidian notes for each class and week of TDF. You'll see that all files are markdown, so use whatever viewer you please, although it's easiest directly in Github. I write these in-class in Obsidian and publish to Github before the start of the next class.

The file naming convention is mmddyyyy

Typically I'll take daily notes each class, and then merge into weekly notes on Fridays.
